{#- The one command that installs or upgrades the update helper, for this release. -#} 
curl -fsSLO https://raw.githubusercontent.com/aistuartai/Googich_takeaway/v{{ version }}/deploy/updater/install-updater.sh
sudo bash install-updater.sh /opt/googich
Run it on the Docker host, in any folder; change /opt/googich if compose.yaml is elsewhere. Read the script first if you like: it is short, and it runs as root.
