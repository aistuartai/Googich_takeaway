The daily check only shows a notice. With the update helper, the update button installs a release when you press it; nothing installs on its own. Checks ask GitHub anonymously for the latest release of this project.

For testing only. A release candidate is a test build of the next release, published so it can be tried before everyone gets it. It can have bugs, including ones that stop an import part way.

Your settings and history are kept when you update. Switching this off again does not take you back to the last final release: you stay on the candidate until a newer final release replaces it.
