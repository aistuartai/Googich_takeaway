# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report privately through GitHub: open the repository's **Security** tab and choose
**Report a vulnerability**. Include the version, what you found, and steps to reproduce.

You can expect an acknowledgement within 7 days.

## Handling secrets

Googich Takeaway stores Google and Immich credentials. Never paste credentials, API keys, or
service account files into issues, pull requests, or logs you share. If you believe a credential
has been exposed, revoke it first, then report.
